# Operator Intent Interpretation

## Purpose
Interpret vague or partial human steering in a way that preserves mission momentum.

## Procedure
1. Identify whether the operator is redirecting scope, method, priority, or output style.
2. Infer the narrowest safe interpretation that matches the signal.
3. Avoid unnecessary clarification when the path is reasonably clear.
4. Record what changed.

## Output
- interpreted intent
- change type
- confidence
- whether clarification is truly needed
