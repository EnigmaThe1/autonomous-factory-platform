# Source Selection Audit

## Purpose
Check whether the chosen sources and freshness level improved mission outcomes.

## Procedure
1. Review the mission archetype and research path.
2. Evaluate whether sources were authoritative enough and fresh enough.
3. Detect over-browsing, stale selection, or poor source diversity.
4. Recommend source-selection improvements.

## Output
- source selection finding
- affected source behavior
- suggested improvement
