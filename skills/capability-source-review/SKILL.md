# Capability Source Review

## Purpose
Evaluate whether a capability's source is suitable for use in the current mission.

## Procedure
1. Read the capability entry.
2. Inspect linked source metadata.
3. Check trust policy compatibility.
4. Classify whether activation is allowed, ask-only, or denied.
5. Record reasoning.

## Output
- capability id
- source id
- compatibility result
- approval requirement
- rationale
