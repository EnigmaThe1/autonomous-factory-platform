# Validation-Layer Self-Improvement

## Purpose
Improve checks, proofs, and confidence-building routes over time.

## Use when
- several missions have required validation
- validation cost and benefit can be compared
- the system should become better at knowing what proof is enough

## Procedure
1. Review validation behavior and outcomes.
2. Compare validation paths against actual confidence and correctness.
3. Detect over-validation, under-validation, and high-value proof routes.
4. Propose soft validation-layer improvements.

## Output
- validation finding
- recommended adjustment
- supporting evidence
- confidence
- rollback condition
