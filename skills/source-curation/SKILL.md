# Source Curation

## Purpose
Review external capability sources before they are relied upon by the universal kernel.

## Procedure
1. Identify candidate source and source type.
2. Determine whether it is official, community, private, or unknown.
3. Record risk, freshness, maintenance status, and scope.
4. Recommend state: discovered, reviewed, approved, mirrored, rejected.
5. Note whether operator approval is required.

## Output
- source summary
- evidence and provenance
- risks
- recommended review state
- activation guidance
