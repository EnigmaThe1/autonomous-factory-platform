# Source Ingestion Planning

## Purpose
Plan how a reviewed source should be introduced without bloating the core kernel.

## Procedure
1. Determine why the source is needed.
2. Identify which capability entries depend on it.
3. Define trust gate and approval requirement.
4. Decide whether to mirror locally or reference remotely.
5. Produce smallest safe ingestion plan.

## Output
- needed capabilities
- source dependency map
- trust gate
- ingestion steps
- rollback guidance
