# Mission Compilation

## Purpose
Turn a vague or broad request into an execution contract that can guide the rest of the workflow.

## Use when
- the user describes a vision instead of a task
- the request is ambiguous
- success criteria are unclear
- it is not obvious whether edits are needed

## Procedure
1. Restate the request in concrete terms.
2. Separate facts from assumptions.
3. Define scope and non-scope.
4. Decide whether file edits are required, optional, or currently unjustified.
5. Identify needed tools and why.
6. Define completion criteria.
7. Recommend the next action.

## Output
- mission summary
- facts
- assumptions
- scope
- required tools
- recommended next step
