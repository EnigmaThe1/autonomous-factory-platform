# Discovery Refresh

## Purpose
Refresh the discovery layer so new or changed capabilities can be staged for review without being trusted or activated automatically.

## Procedure
1. Inspect refresh policy and freshness state.
2. Identify stale sources and stale capability entries.
3. Queue refresh candidates by priority.
4. Record discovered changes in the discovery feed.
5. Stage items into the review queue.
6. Leave trust and activation state unchanged unless separately reviewed.

## Output
- refresh plan
- stale items list
- queued discoveries
- review staging notes
