# Suggestion vs Staging

## Purpose
Decide whether a candidate capability should remain only suggested or should be staged for activation.

## Use when
- a mission reveals missing or helpful capabilities
- several possible plugins, tools, or MCP servers are available
- the system should avoid loading too much too early

## Decision model
Score the capability qualitatively across:
1. necessity for the current or next mission phase
2. strength of fallback options
3. environment compatibility
4. expected impact on speed or quality
5. staging overhead and trust cost

## Output
- decision
- short reasoning
- supporting evidence
- next reevaluation point
