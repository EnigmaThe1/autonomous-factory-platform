# Cross-Mission Learning

## Purpose
Improve future capability decisions using patterns observed across multiple missions.

## Use when
- several missions have been completed
- some capability decisions repeat often
- the system should learn from outcomes without hard-coding rigid rules

## Procedure
1. Review prior mission feedback and promotion history.
2. Identify recurring mission archetypes and execution contexts.
3. Detect capabilities that reliably help or rarely help.
4. Suggest future default biases while preserving autonomy.

## Output
- learned pattern
- affected archetype
- recommended bias
- confidence
