# Capability Registry Maintenance

## Purpose
Keep the capability registry accurate, curated, and useful.

## Use when
- adding a new plugin, MCP server, skill pack, or subagent pack
- reviewing stale or low-value capabilities
- updating descriptions, triggers, or risk metadata

## Procedure
1. Record the capability id and type.
2. Summarize what it does.
3. Define mission triggers that justify activation.
4. Capture required tools and environment expectations.
5. Assign cost and risk ratings conservatively.
6. Note validation requirements and known limitations.
7. Remove or downgrade stale entries when appropriate.

## Output
- added or updated registry entry
- rationale
- activation guidance
- validation notes
