# Activation Readiness

## Purpose
Determine whether a capability is sufficiently justified to move from suggested to staged_for_activation.

## Procedure
1. Identify the mission phase that would use the capability.
2. Check whether that phase is active or imminent.
3. Check environment fit and trust posture.
4. Check whether a simpler local alternative exists.
5. Recommend one of:
   - stay_suggested
   - stage_for_activation
   - defer_until_trigger

## Output
- readiness verdict
- evidence summary
- trigger conditions
