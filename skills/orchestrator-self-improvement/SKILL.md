# Orchestrator Self-Improvement

## Purpose
Improve execution flow, agent routing, and escalation timing using downstream evidence from multiple missions.

## Use when
- several missions have been executed
- routing and escalation outcomes can be compared
- the system should improve coordination quality over time

## Procedure
1. Review mission flow and orchestration outcomes.
2. Compare route choices with execution quality.
3. Detect recurring orchestration weaknesses or strengths.
4. Propose soft orchestration improvements.

## Output
- orchestration finding
- recommended adjustment
- supporting evidence
- confidence
- rollback condition
