# Capability Activation Plan

## Purpose
Turn selected capabilities into a phased activation plan.

## Use when
- capability selection is complete
- the workflow needs staged activation rather than loading everything immediately

## Procedure
1. Start with the always-on kernel.
2. Add only required-now capabilities to phase 1.
3. Defer useful-later capabilities until their trigger condition is reached.
4. Define what should never be activated for this mission.
5. For each activation, note:
   - why it is needed
   - expected resource cost
   - risk level
   - validation requirement
6. Produce a reviewable, ordered activation plan.

## Output
- phase 0: kernel only
- phase 1 activations
- phase 2 conditional activations
- forbidden/unnecessary capabilities
- validation checkpoints
