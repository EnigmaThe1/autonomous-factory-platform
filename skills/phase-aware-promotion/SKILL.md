# Phase-Aware Promotion

## Purpose
Adjust capability decisions according to the mission phase rather than treating the mission as one flat block of need.

## Use when
- a mission has multiple phases
- some capabilities matter later but not now
- the system should avoid loading too much too early

## Procedure
1. Identify current phase and next likely phase.
2. Map candidate capabilities to the phases they serve.
3. Keep capabilities suggested when their useful phase is distant.
4. Stage capabilities when their useful phase is current or imminent.
5. Defer only when a clear future trigger is known.

## Output
- phase-aware decision
- reason
- next reevaluation point
