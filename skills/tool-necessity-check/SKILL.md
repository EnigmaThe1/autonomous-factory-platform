# Tool Necessity Check

## Purpose
Decide whether a tool, file edit, web lookup, or subagent is actually needed.

## Use when
- the workflow is becoming too complex
- multiple tools seem possible
- there is a risk of over-automation

## Procedure
1. State the immediate goal.
2. Check whether the current context already supports it.
3. Justify each extra tool or subagent.
4. Prefer the simpler sufficient path.
5. Explicitly say when no additional tool is needed.

## Output
- goal
- candidate tools
- selected tools with reasons
- rejected tools with reasons
