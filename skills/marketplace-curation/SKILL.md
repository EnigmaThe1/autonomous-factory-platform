# Marketplace Curation

## Purpose
Research and record trusted marketplace or official-source capabilities without auto-installing them.

## Procedure
1. Prefer official docs and first-party marketplaces.
2. Record install source, trust tier, and known limits.
3. Distinguish between suggested, approved, and blocked sources.
4. Update the registry or a review note instead of silently enabling everything.

## Output
- source
- capability
- trust assessment
- approval recommendation
- registry update notes
