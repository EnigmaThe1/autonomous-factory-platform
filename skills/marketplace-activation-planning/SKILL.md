# Marketplace Activation Planning

## Purpose
Plan how a capability should be activated from a marketplace-aware source flow.

## Procedure
1. Identify the capability and preferred source.
2. Check whether the source is reviewed and approved.
3. Check whether a local mirror already exists.
4. Prefer local mirror activation where practical.
5. Produce an activation checklist with approvals and validation.

## Output
- capability
- source
- source state
- mirror state
- activation steps
- validation steps
