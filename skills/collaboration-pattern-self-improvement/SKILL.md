# Collaboration-Pattern Self-Improvement

## Purpose
Improve how the system chooses the best collaboration shape for a task.

## Use when
- several missions have been completed
- collaboration styles can be compared against outcomes
- the system should learn not just how to execute, but how many and what kinds of agents should be involved

## Procedure
1. Review the mission type and chosen collaboration shape.
2. Compare that shape against actual progress, coordination friction, and result quality.
3. Detect where a different collaboration pattern would likely have worked better.
4. Propose soft collaboration-pattern improvements.

## Output
- collaboration finding
- recommended adjustment
- supporting evidence
- confidence
- rollback condition
