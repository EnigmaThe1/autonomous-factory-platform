# Repo Discovery

## Purpose
Inspect a repository before planning or implementation.

## Use when
- the structure is unfamiliar
- the user refers to existing code or files
- it is unclear whether the requested capability already exists

## Procedure
1. Locate likely relevant files and configs.
2. Identify entrypoints, tests, and recurring patterns.
3. Check whether the feature already exists or partially exists.
4. Report what is known and what is still uncertain.

## Output
- relevant paths
- current behavior
- evidence
- gaps / uncertainty
