# Freshness Audit

## Purpose
Determine which capability, source, and review records need revalidation.

## Procedure
1. Check last seen, last reviewed, and expiry windows.
2. Categorize items as fresh, warning, stale, or unknown.
3. Prioritize by mission relevance and risk.
4. Recommend the smallest useful refresh cycle.

## Output
- freshness summary
- stale candidates
- recommended refresh cadence
