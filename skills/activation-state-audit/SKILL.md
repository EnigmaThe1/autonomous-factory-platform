# Activation State Audit

## Purpose
Audit whether capability lifecycle states and recorded history remain coherent.

## Procedure
1. Read activation-state, activation-requests, and activation-history.
2. Check for impossible transitions.
3. Check for activated capabilities lacking approval.
4. Check for retired capabilities still marked active.
5. Report inconsistencies and recommended fixes.

## Output
- findings
- inconsistent entries
- recommended corrections
