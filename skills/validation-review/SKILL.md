# Validation Review

## Purpose
Check whether the completed work was actually validated well enough.

## Use when
- changes were made
- an investigation produced recommendations
- confidence needs to be assessed

## Procedure
1. List what changed or what was concluded.
2. List validations performed.
3. Identify missing validation.
4. Assess residual risk.
5. Produce an honest pass / partial / fail result.

## Output
- validation summary
- missing checks
- risk assessment
- verdict
