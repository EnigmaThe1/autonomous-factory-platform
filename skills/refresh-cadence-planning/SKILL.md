# Refresh Cadence Planning

## Purpose
Choose how often different kinds of capability intelligence should be refreshed.

## Procedure
1. Classify each item by volatility and risk.
2. Assign a cadence such as weekly, monthly, quarterly, or manual.
3. Prefer lighter review for stable trusted sources.
4. Prefer tighter review for marketplace and community sources.

## Output
- cadence map
- rationale
- high-priority refresh schedule
