# Execution-Strategy Self-Improvement

## Purpose
Improve how the system chooses the best overall way to execute a task.

## Use when
- several missions have been completed
- approach patterns can be compared against results
- the system should learn not just which tools to use, but how to approach the work itself

## Procedure
1. Review the mission type and chosen execution style.
2. Compare that style against actual progress, friction, and result quality.
3. Detect where a different approach pattern would likely have worked better.
4. Propose soft execution-strategy improvements.

## Output
- strategy finding
- recommended adjustment
- supporting evidence
- confidence
- rollback condition
