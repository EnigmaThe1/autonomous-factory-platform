# Self-Improvement Governance

## Purpose
Govern how learned adaptations mature from tentative signals into stronger soft defaults.

## Use when
- multiple self-improvement layers are active
- the system is accumulating enough learning that maturity and stability now matter
- there is a risk of overreacting to weak or recent evidence

## Procedure
1. Review recent and cross-mission improvements.
2. Classify each adaptation by evidence maturity.
3. Decide whether it should remain tentative, become a stronger soft default, or be damped/rolled back.
4. Preserve autonomy-first behavior while improving stability.

## Output
- governed adaptation
- maturity classification
- recommended action
- supporting evidence
- confidence
- rollback condition
