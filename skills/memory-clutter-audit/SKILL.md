# Memory Clutter Audit

## Purpose
Check whether memory retention and surfacing are too noisy, too weak, or well balanced.

## Procedure
1. Review retained items and summaries.
2. Compare them with future usefulness.
3. Detect over-retention, under-retention, and poor compression.
4. Recommend focused memory adjustments.

## Output
- memory quality finding
- affected memory area
- suggested improvement
