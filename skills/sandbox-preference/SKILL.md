# Sandbox Preference

## Purpose
Recommend safer execution zones when they add value, while preserving broad freedom inside the project/task space.

## Procedure
1. Identify whether safer zones exist.
2. Determine whether the mission really benefits from them.
3. Recommend soft preference unless host integrity is at risk.
4. Keep normal project work free-flowing when sandboxing is unnecessary.

## Output
- available safer zones
- when to prefer them
- what can remain in normal workspace
- host-integrity concerns
