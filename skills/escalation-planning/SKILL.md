# Escalation Planning

## Purpose
Determine whether a mission should stay single-agent, use specialists, or use a broader team.

## Procedure
1. Evaluate complexity, ambiguity, and risk.
2. Estimate value of parallelism.
3. Estimate coordination cost.
4. Compare execution modes.
5. Recommend the lightest viable mode.

## Output
- candidate execution modes
- pros and cons
- chosen mode
- rejected modes and reasons
- escalation checkpoints
