# Trust Evaluation

## Purpose
Decide whether a capability can be auto-enabled, should ask for approval, should remain deferred, or should be blocked.

## Procedure
1. Identify the mission need.
2. List candidate capabilities.
3. Classify each by trust tier and risk band.
4. Prefer local and existing capabilities before suggesting new installs.
5. Produce an activation decision for each candidate.

## Output
- candidate capability
- trust tier
- risk band
- decision
- reason
- follow-up validation
