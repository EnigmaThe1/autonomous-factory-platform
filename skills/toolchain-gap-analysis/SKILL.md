# Toolchain Gap Analysis

## Purpose
Compare mission needs against current capabilities and identify the smallest useful expansion set.

## Procedure
1. Read the mission contract.
2. Read capability registry and currently available tools.
3. Classify needs as required, useful, or optional.
4. Identify missing plugins, skills, scripts, MCP servers, or templates.
5. Recommend the smallest useful expansion first.

## Output
- required capabilities
- available capabilities
- detected gaps
- smallest useful expansion set
- deferred optional expansions
