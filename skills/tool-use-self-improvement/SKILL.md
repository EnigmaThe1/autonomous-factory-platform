# Tool-Use Self-Improvement

## Purpose
Improve concrete tool choice and tool combination quality using multi-mission evidence.

## Use when
- several missions have been executed
- tool choices can be compared against outcomes
- the system should learn which tools and combinations actually help

## Procedure
1. Review tool-use history and mission outcomes.
2. Detect useful, low-value, and high-friction tool patterns.
3. Compare tool combinations against execution and validation quality.
4. Propose soft tool-use improvements.

## Output
- tool-use finding
- recommended adjustment
- supporting evidence
- confidence
- rollback condition
