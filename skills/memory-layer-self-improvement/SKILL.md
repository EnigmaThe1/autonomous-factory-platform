# Memory-Layer Self-Improvement

## Purpose
Improve what the system remembers, summarizes, surfaces, and forgets.

## Use when
- several missions have accumulated reusable knowledge
- memory clutter or missing recall is affecting performance
- the system should retain knowledge more selectively

## Procedure
1. Review cross-mission artifacts and outcomes.
2. Identify what should be retained, summarized, or forgotten.
3. Detect repeated memory clutter or missing recall.
4. Propose soft memory-policy improvements.

## Output
- memory finding
- recommended adjustment
- supporting evidence
- confidence
- rollback condition
