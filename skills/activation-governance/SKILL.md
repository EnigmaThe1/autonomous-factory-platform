# Activation Governance

## Purpose
Turn selected capabilities into a phased, minimal activation plan.

## Procedure
1. Separate always-on core from optional capabilities.
2. Group optional capabilities by mission phase.
3. Mark what is already available versus what needs install or approval.
4. Keep high-cost or high-risk items deferred until they are truly needed.
5. Emit a reload and validation checklist.

## Output
- phase order
- activate now
- defer
- require approval
- reload/check commands
