# Goal-Formation Self-Improvement

## Purpose
Improve how vague user end-goals are turned into sharper mission intents before compilation.

## Use when
- several missions began from broad or underspecified goals
- downstream execution exposed weak early goal shaping
- the system should get better at turning intent into a strong starting direction

## Procedure
1. Review raw goals and resulting mission trajectories.
2. Detect recurring ambiguity patterns.
3. Identify what should have been sharpened earlier.
4. Propose soft goal-formation improvements.

## Output
- goal-shaping finding
- recommended adjustment
- supporting evidence
- confidence
- rollback condition
