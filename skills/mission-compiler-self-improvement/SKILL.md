# Mission Compiler Self-Improvement

## Purpose
Improve how raw mission prompts are compiled into execution contracts over time.

## Use when
- several missions have been run
- downstream execution revealed recurring prompt-to-plan weaknesses
- the system should improve task decomposition quality

## Procedure
1. Review raw mission prompts.
2. Review compiled contracts.
3. Review downstream friction and execution outcomes.
4. Detect recurring compiler weaknesses.
5. Suggest soft improvements to mission compilation heuristics.

## Output
- compiler weakness
- recommended improvement
- supporting evidence
- confidence
- rollback condition
