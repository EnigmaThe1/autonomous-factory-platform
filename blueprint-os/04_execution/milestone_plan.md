# Milestone Plan

## M1 — Standalone skeleton online
Core services boot, dashboard reachable, database connected.

## M2 — Mission compiler operational
Raw mission intake becomes compiled contract before execution.

## M3 — Orchestrator operational
Mission queue, work-item execution, and visible outcomes function end to end.

## M4 — Evidence/recovery engine operational
Tool necessity and sufficiency decisions affect runtime behavior.

## M5 — Dashboard operator parity
The standalone UI reaches or exceeds the useful operator functionality of the extension.

## M6 — Thin adapter alpha
Editor/CLI adapters can start and observe missions against the backend.

## M7 — Regression matrix pass
The first matrix mission family passes on the standalone platform.
