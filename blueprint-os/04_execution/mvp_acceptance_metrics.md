# MVP acceptance metrics

## Mission quality
- visible outcome rate after operator actions: 100%
- silent no-op rate: 0%
- missions completed without manual rescue: target >= 70% for supported families

## Compiler quality
- safe path normalization success rate
- input/output confusion prevented before execution
- blocked ambiguities surfaced before work starts

## Recovery quality
- optional tool failures converted to degrade/replan instead of block where appropriate
- invalid early completion rate reduced over baseline

## UX quality
- start-to-visible-outcome latency
- time to first useful mission action
- operator clarity rating in regression matrix
