# Usage Guide

## How to use this package for Autonomous Factory

1. Treat this package as the live planning and architecture set for the standalone platform.
2. Start implementation from `04_execution/implementation_plan.md`.
3. Use the ledger to track actual progress and migration truth.
4. Use the roadmap and matrix docs to decide validation order.
5. When a future standalone repo exists, copy this package into its canonical docs location and continue updating it there.

## Recommended use after v2
Use the canonical blueprint plus the v2 enhancement files together. Do not treat the enhancement files as optional commentary; they refine the platform contract.
