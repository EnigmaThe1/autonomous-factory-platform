# Operator Experience

## UX goals
- start missions with confidence
- understand what the platform is doing and why
- see blocked/error states immediately
- inspect compiler findings before and during execution
- review reports and approvals without hunting through logs

## Mission start expectations
A start attempt must always result in:
- visible mission registration, or
- visible blocked/error state, or
- explicit operator-facing error

## Inspection expectations
Operators should be able to inspect:
- current mission contract
- compiler findings
- evidence contract status
- recovery route chosen
- latest agent activity
- final reports and validation outcome
