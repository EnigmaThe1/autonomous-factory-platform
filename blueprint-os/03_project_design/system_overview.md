# System Overview

## Project name
Autonomous Factory

## System purpose
A standalone AI-native platform that runs governed autonomous software-delivery missions over real repositories and workspaces.

## Who it serves
Builders and engineering operators who want a reliable autonomous mission system without depending on fragile editor-host behavior.

## Problem statement
The previous extension-centric model proved valuable conceptually but brittle operationally. The system needs to own its runtime, UI, persistence, and execution model directly.

## Main value provided
- mission compilation from rough intent
- specialized multi-agent execution
- bounded autonomy with evidence and recoverability
- durable reports and diagnostics
- thin adapter support for editor convenience without editor lock-in

## AI role
AI is the core execution intelligence, not a bolt-on helper. It interprets, plans, researches, implements, reviews, validates, and assists operators within governed boundaries.

## What finished looks like
A platform where the operator can start a mission from the web dashboard or an adapter, watch the controller compile and run it, inspect evidence and reports, grant approvals when needed, and trust that failures are visible, recoverable, and auditable.
