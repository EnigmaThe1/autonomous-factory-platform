# State Model

## Mission-level state
- id, title, raw prompt
- compiled contract
- compiler findings
- status
- runtime counters
- focused artifacts
- approvals summary
- final verdict state

## Work-item state
- id, role, title
- status
- dependency links
- expected deliverables
- evidence contract reference
- retry/recovery metadata

## Diagnostics state
- interaction ids / trace ids
- start-action outcomes
- compiler metrics
- action bridge outcomes
- refresh/publication state
