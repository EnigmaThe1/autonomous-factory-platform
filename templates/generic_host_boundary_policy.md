# Generic Host Boundary Policy

## Principle
Protect the host, not the intelligence.

## Hard boundary
Only block actions that could damage machine integrity, critical system configuration, or host-sensitive credential stores.

## Soft guidance
Everything inside normal project and task space should remain flexible:
- planning
- agent routing
- implementation strategy
- dynamic replanning
- use of subagents
- capability expansion when justified

## Project customization
Projects may extend this policy, but should avoid turning ordinary work into excessive bureaucracy.
